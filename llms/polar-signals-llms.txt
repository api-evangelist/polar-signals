# Polar Signals

> Continuous profiling for production systems. Polar Signals Cloud uses eBPF to
> profile CPU, memory and NVIDIA GPU workloads across Kubernetes, Docker, ECS
> and bare metal with under 1% overhead and no code changes, storing profiles
> in the open-source FrostDB columnar database and querying them with
> Prometheus-style label selectors. Built by the team behind the open-source
> Parca project.

## APIs

- [Polar Signals Cloud API (gRPC/Connect)](https://buf.build/polarsignals/api): organizations, projects, service accounts, tokens, RBAC roles, rate limits, billing
- [Profiling data plane](https://www.polarsignals.com/docs/generating-tokens): grpc.polarsignals.com:443 (profile uploads), api.polarsignals.com:443 (symbol/debuginfo uploads); Parca-compatible
